## Kontor 1.0.1

- Updates installieren sich jetzt in einem Rutsch: Nach dem einmaligen Erlauben geht es automatisch weiter
- Nach einem Update meldet sich Kontor mit einer Benachrichtigung
- Das Update-Banner führt direkt zum Update in den Einstellungen
- Löschen eines Eintrags springt nicht mehr eine Seite zu weit zurück
- Leere Kategorien zeigen einen Hinweis
