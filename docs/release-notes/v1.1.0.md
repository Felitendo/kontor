## Kontor 1.1: Umzug aufs neue Handy

- **Umzug aufs neue Handy** per QR-Codes von Bildschirm zu Bildschirm oder als Datei, ganz ohne Internet. Deine Einstellungen ziehen mit um
- Auf einem neuen Handy gleich beim Start **„Von altem Handy übernehmen“**
- **Schütteln zum Verbergen**: Handy kurz schütteln blendet alle Beträge aus oder ein
- **Vibration** funktioniert jetzt auf allen Handys, mit der neuen Stufe „Kräftig“ für schwache Motoren und „Vibration testen“
- **Bank-Logos** auch für von Hand eingetragene Banken, neu dabei ist Chase
- **Große Schrift**: Aufteilung, Listen und Beträge passen sich an, nichts wird mehr abgeschnitten oder mitten in einer Zahl umgebrochen
- Ruhigere Zahlen beim Scrubben durch den Chart
- Bindestriche sehen wieder normal aus („QR-Code“ statt „QR - Code“)
- Sicherungen aus Version 1.0 lassen sich weiterhin einspielen
